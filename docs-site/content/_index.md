# ExpLedger

Keep coding experiments as ordinary folders in your project, with structured
metadata, independent notes, and a script you can run in place.

Start with [Getting started](/docs/getting-started.md), then explore
[Configuration](/docs/configuration.md),
[Running experiments](/docs/running.md), and the
[Experiment format](/docs/format.md).
The [CLI reference](/docs/reference/expledger.md) lists commands,
examples, and flags directly from the CLI.

ExpLedger is in active development. Expect breaking changes.
